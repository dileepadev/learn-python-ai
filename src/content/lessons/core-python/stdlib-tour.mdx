Python ships with most of what an AI pipeline needs before you install anything. This is a tour
of the parts you will actually use, and why each one turns up.

## collections

`Counter` counts, `defaultdict` groups, `deque` is a queue with a fixed memory:

<Run id="cp-std-1" code={`from collections import Counter, defaultdict, deque

tokens = "the model saw the token the model produced".split()

counts = Counter(tokens)
print(counts.most_common(3))
print("vocabulary size:", len(counts))
print("hapaxes:", [word for word, n in counts.items() if n == 1])

# defaultdict: no "if key not in d" dance
by_language = defaultdict(list)
for doc in [("en", "intro"), ("si", "guide"), ("en", "faq")]:
    by_language[doc[0]].append(doc[1])
print(dict(by_language))

# deque with maxlen: keep only the last N turns of a conversation
window = deque(maxlen=3)
for turn in ["t1", "t2", "t3", "t4", "t5"]:
    window.append(turn)
print(list(window))`} />

A `deque(maxlen=n)` is the sliding context window in one line: append forever, and it silently
drops the oldest.

## statistics

<Run id="cp-std-2" code={`import statistics

latencies = [120, 95, 340, 110, 2100, 130, 105, 98]

print("mean:  ", round(statistics.mean(latencies), 1))
print("median:", statistics.median(latencies))
print("stdev: ", round(statistics.stdev(latencies), 1))
print("p95:   ", round(statistics.quantiles(latencies, n=20)[-1], 1))`} />

The mean is 387 ms and the median is 115 ms. Report the median and a high percentile for
latency — one slow request should not be allowed to describe the typical experience.

## random, and seeding it

<Run id="cp-std-3" code={`import random

random.seed(42)
print([round(random.random(), 4) for _ in range(3)])
print(random.choice(["opus", "sonnet", "haiku"]))
print(random.sample(range(100), 5))

random.seed(42)                     # same seed, same sequence
print([round(random.random(), 4) for _ in range(3)])

# Shuffling a dataset reproducibly:
examples = list(range(10))
random.Random(7).shuffle(examples)  # an isolated generator, seeded
print(examples)`} />

<Callout type="ai" title="Why this matters for AI">
Seeding is the difference between an experiment and an anecdote. The train/test split, the
shuffle, the subsample you evaluated on, the dropout mask — all of them are random, and all of
them change your reported score. Seed every source of randomness and record the seed next to the
result. `random.Random(seed)` gives you a private generator, so seeding your pipeline does not
quietly reseed a library's.
</Callout>

## hashlib

A hash turns content into a short, stable fingerprint. It is how you build a cache key, spot a
duplicate document, and give a chunk an id that does not change between runs:

<Run id="cp-std-4" code={`import hashlib, json

def fingerprint(text):
    return hashlib.sha256(text.encode("utf-8")).hexdigest()[:16]

a = "Retrieval augmented generation grounds an answer in your documents."
b = "Retrieval augmented generation grounds an answer in your documents."
c = "A different sentence entirely."

print(fingerprint(a))
print(fingerprint(b), "same content, same id")
print(fingerprint(c))

# A cache key for a whole request — sorted keys make it order-independent.
def cache_key(model, prompt, **options):
    payload = json.dumps({"model": model, "prompt": prompt, **options}, sort_keys=True)
    return hashlib.sha256(payload.encode("utf-8")).hexdigest()[:16]

print(cache_key("claude-opus-5", "Hi", temperature=0, max_tokens=64))
print(cache_key("claude-opus-5", "Hi", max_tokens=64, temperature=0), "order does not matter")`} />

<Callout type="warning">
`hash()`, the built-in, is **not** stable across processes — Python randomises string hashing for
security, so the same string gives a different number in tomorrow's run. For anything you persist
or compare across runs, use `hashlib`.
</Callout>

## Regular expressions

`re` is for finding and reshaping patterns in text. Always write the pattern as a raw string, so
backslashes reach the regex engine intact:

<Run id="cp-std-5" code={`import re

log = "run=42 model=claude-opus-5 latency=134ms tokens=412 status=ok"

print(re.findall(r"(\\w+)=(\\S+)", log))
print(dict(re.findall(r"(\\w+)=(\\S+)", log)))

match = re.search(r"latency=(\\d+)ms", log)
print("latency:", int(match.group(1)) if match else "not found")

# Cleaning: collapse whitespace, strip control characters, drop URLs.
messy = "  Visit   https://example.com for  the   docs.\\n\\n Thanks!  "
cleaned = re.sub(r"https?://\\S+", "", messy)
cleaned = re.sub(r"\\s+", " ", cleaned).strip()
print(repr(cleaned))

# Splitting a document into sentences, roughly.
text = "First sentence. Second one! And a third? Yes."
print(re.split(r"(?<=[.!?])\\s+", text))`} />

<Callout type="tip">
Reach for a string method first. `text.startswith(...)`, `.split()`, `.replace()` and `in` are
faster to write, faster to run and far easier to read than the regex that does the same thing.
</Callout>

## datetime

<Run id="cp-std-6" code={`from datetime import datetime, timezone, timedelta

now = datetime.now(timezone.utc)          # always timezone-aware
print(now.isoformat(timespec="seconds"))
print(now.strftime("%Y-%m-%d %H:%M"))

deadline = now + timedelta(minutes=30)
print("30 minutes on:", deadline.isoformat(timespec="seconds"))
print("difference:   ", deadline - now)

parsed = datetime.fromisoformat("2026-03-01T09:30:00+00:00")
print("parsed:", parsed, parsed.tzinfo)`} />

Store timestamps in UTC and as ISO strings. A naive `datetime.now()` is ambiguous the moment your
code runs on a machine in another timezone, which it will.

## Timing

<Run id="cp-std-7" code={`import time

started = time.perf_counter()
total = sum(n * n for n in range(300_000))
elapsed = time.perf_counter() - started

print(f"computed {total}")
print(f"took {elapsed * 1000:.1f} ms")`} />

Use `time.perf_counter()` for durations — it is monotonic, so it cannot go backwards when the
system clock is adjusted. `time.time()` is for wall-clock timestamps, not measurement.

## Environment variables

Configuration and secrets come from the environment, never from the source file:

<Run id="cp-std-8" code={`import os

# Pretend the shell had already exported these.
os.environ["MODEL"] = "claude-opus-5"

print("model:     ", os.environ.get("MODEL", "claude-haiku-4-5"))
print("max tokens:", int(os.environ.get("MAX_TOKENS", "1024")))
print("debug:     ", os.environ.get("DEBUG", "").lower() in {"1", "true", "yes"})

api_key = os.environ.get("ANTHROPIC_API_KEY")
if api_key is None:
    print("no API key set — running against fixtures instead")`} />

Note that every value arrives as a **string**: `int(...)` for numbers, and an explicit comparison
for booleans, because `bool("false")` is `True`.

<Callout type="warning">
Never write an API key into a source file, a notebook or a commit. Read it from the environment,
keep it in an untracked `.env`, and make the code fall back to fixtures when it is absent — as
this page does, since a static site has nowhere safe to put one.
</Callout>

## textwrap and uuid

<Run id="cp-std-9" code={`import textwrap, uuid

prompt = "You are a careful assistant. Answer only from the provided context, and say when you do not know."

print(textwrap.fill(prompt, width=60))
print()
print(textwrap.shorten(prompt, width=50, placeholder=" …"))

`textwrap.dedent` is the one to remember for prompts written as triple-quoted strings — it strips
the indentation your code has but your prompt should not:

<Run id="cp-std-10" code={`import textwrap

def build_prompt(question):
    raw = f"""
        You are a careful assistant.

        Question: {question}
        Answer:
    """
    return textwrap.dedent(raw).strip()

print(repr(build_prompt("What is a token?")))
print()
print(build_prompt("What is a token?"))`} />

## Recap

- `Counter` counts, `defaultdict` groups without key checks, and `deque(maxlen=n)` is a sliding
  window.
- Report the median and a percentile for latency, not the mean.
- Seed every source of randomness and record the seed; `random.Random(seed)` keeps it private.
- `hashlib` gives stable fingerprints for cache keys and de-duplication; the built-in `hash()`
  does not survive a restart.
- Use raw strings for regex patterns, and a string method when one will do.
- Keep timestamps timezone-aware and in UTC; measure durations with `time.perf_counter()`.
- Read configuration and secrets from `os.environ`, converting the strings it hands you.
