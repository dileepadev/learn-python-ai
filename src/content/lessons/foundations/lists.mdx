A list holds an ordered collection of anything, and unlike a string, you can change it in
place.

<Run id="f-list-1" code={`fruits = ["apple", "banana", "cherry"]

print(fruits)
print(fruits[0], fruits[1], fruits[-1])
print(len(fruits))
print(type(fruits))`} />

Lists are heterogeneous — Python does not require the items to share a type:

<Run id="f-list-2" code={`mixed = ["text", 42, 3.14, True, None, [1, 2]]

for item in mixed:
    print(f"{str(item):<8} {type(item).__name__}")`} />

In practice you almost always want a list of *one* kind of thing. A list of mixed types usually
means the data should have been a dictionary.

## Changing a list

<Run id="f-list-3" code={`fruits = ["apple", "banana", "cherry"]

fruits[0] = "orange"          # replace by index
print(fruits)

fruits.append("grape")        # add one to the end
print(fruits)

fruits.insert(1, "kiwi")      # add at a position
print(fruits)

fruits.extend(["fig", "date"])  # add several
print(fruits)

fruits.remove("banana")       # remove by value (first match)
print(fruits)

last = fruits.pop()           # remove and return the last
print(last, "->", fruits)

del fruits[0]                 # remove by index
print(fruits)`} />

<Callout type="warning">
`append` adds one item; `extend` adds each item of an iterable. `["a"].append(["b","c"])`
gives `["a", ["b","c"]]` — a nested list, almost never what you meant.
</Callout>

## Searching and counting

<Run id="f-list-4" code={`numbers = [1, 3, 2, 5, 4, 3]

print(3 in numbers)
print(numbers.count(3))
print(numbers.index(5))     # first position of the value
print(min(numbers), max(numbers), sum(numbers))`} />

`index` raises a `ValueError` if the value is not there, so check with `in` first when you are
not sure.

## Sorting

There are two ways, and the difference matters.

<Run id="f-list-5" code={`numbers = [5, 3, 1, 4, 2]

ordered = sorted(numbers)     # returns a NEW list
print(ordered, numbers)

numbers.sort()                # sorts IN PLACE, returns None
print(numbers)

numbers.sort(reverse=True)
print(numbers)

numbers.reverse()             # just flips the order
print(numbers)`} />

`sorted()` works on anything iterable and leaves the original alone. `.sort()` is a list method
that mutates. A common mistake is `numbers = numbers.sort()`, which sets `numbers` to `None`.

Sorting by a computed key is where it gets useful:

<Run id="f-list-6" code={`runs = [
    ("baseline", 0.71),
    ("ensemble", 0.91),
    ("tuned", 0.88),
]

# Sort by the second element of each tuple, highest first.
best_first = sorted(runs, key=lambda run: run[1], reverse=True)
for name, score in best_first:
    print(f"{name:<10} {score:.0%}")`} />

## Slicing works exactly as it does on strings

<Run id="f-list-7" code={`devices = ["laptop", "phone", "tablet", "watch", "desktop", "printer", "router"]

print(devices[1:3])
print(devices[:2])
print(devices[3:])
print(devices[-2:])
print(devices[::2])
print(devices[::-1])`} />

## A list is a reference

This catches everyone once. Assigning a list to a new name does not copy it.

<Run id="f-list-8" code={`original = [1, 2, 3]
alias = original          # the SAME list, two names
copy = original[:]        # a real copy (list(original) also works)

alias.append(999)

print("original:", original)
print("alias:   ", alias)
print("copy:    ", copy)`} />

<Callout type="ai" title="Why this matters for AI">
This is the bug behind "my training data changed after I split it". If you slice a dataset and
then shuffle or normalise the slice in place, you may be mutating the original. When in doubt,
copy explicitly — <code>list(x)</code>, <code>x[:]</code> or <code>copy.deepcopy(x)</code> for
nested structures.
</Callout>

## Building lists with a loop — then without one

The long way:

<Run id="f-list-9" code={`squares = []
for n in range(1, 8):
    squares.append(n * n)

print(squares)`} />

The Python way — a **list comprehension**:

<Run id="f-list-10" code={`squares = [n * n for n in range(1, 8)]
print(squares)

# With a filter:
evens = [n for n in range(1, 21) if n % 2 == 0]
print(evens)

# Transforming existing data:
names = ["  ada ", "GRACE", "Alan  "]
cleaned = [name.strip().title() for name in names]
print(cleaned)`} />

Read it left to right: *the expression*, *for each item*, *if the condition holds*. It is
shorter, and — because Python does the looping internally — usually faster.

## Recap

- Lists are ordered, mutable and can hold anything.
- `append` adds one item, `extend` adds many, `pop` removes and returns.
- `sorted(x)` returns a new list; `x.sort()` mutates and returns `None`.
- Assignment shares a list; use `x[:]` or `list(x)` to copy.
- A list comprehension is the idiomatic way to build a list from another sequence.
