# Standalone examples

These are plain `.py` files you can run on your own machine with a local Python
install:

```bash
python examples/introduction/hello_world.py
```

They cover the same ground as **Module 1 — Python Foundations** on the site, in a
form you can open in an editor and step through with a debugger.

The lessons at [dileepadev.github.io/learn-python-ai](https://dileepadev.github.io/learn-python-ai)
are the canonical, maintained version: they carry the explanations, the exercises
with automatic checking, and a Python runtime that needs no installation. Treat
these files as a companion, not a replacement.
