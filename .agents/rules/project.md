# Project guidance

All contributor and agent guidance for this repository lives in one file:
`AGENT.md` at the repository root — **read it before making any change.**

It covers the project's purpose and principles, the commands, the architecture and the decisions
behind it, how to write a lesson, the exercise-checking contract, the commit, branch, issue and
PR conventions, the browser-sandbox constraints, and the definition of done.

This rule is only a pointer. Do not add guidance here — it belongs in `AGENT.md`, so that every
tool reads the same thing.
